# CRM 前端性能基线（隔离夹具）

在仓库根目录运行：

```powershell
npm run test:performance:baseline
```

脚本复用 `tests/regression/browser.cjs` 的本地浏览器与网络限制，设置 1024×768 iPad 视口，并直接加载真实 Console 页面模块。API 响应由脚本内虚构数据提供，不调用 CloudBase、云函数或生产数据库，也不执行写入。目录路径使用 1,240 条虚构总量、30 条 iPad 页数据；人物时间线与 OCR 导入队列每页 20 条；每条场景默认采样 10 次，可通过 `CRM_PERF_ITERATIONS` 设置为 5 到 30 次。正式比较时推荐 30 次采样；高负载下 CDP 超时会在 `.results/baseline-failure-*.json` 留下诊断。

覆盖路径：人物目录、客户经营筛选、人物总览、人物跟进时间线、招募目录、活动目录、人物附件导入队列状态、知识治理页的导入处理状态。对目录和队列请求执行第 2 页检查；知识治理页的 20 行分页为客户端分页。

结果写入忽略目录 `tests/performance/.results/`，包括 `baseline.json` 最新结果和按时间/提交归档的完整 JSON。指标包括交互渲染时间、mock API 处理时间、请求数、请求/响应 JSON 字节、可见行数、重复请求、DOM 节点数、分页响应与浏览器长任务。

这些时间不代表线上网络或 CloudBase 服务性能。基线仅能比较客户端渲染和固定合成响应的开销；不能据此断言生产页面的真实 p95、请求耗时或数据库热点。需要评估线上性能时，须另行授权真实登录/读取方案，在隔离环境用经过批准的数据测量服务时延，并避免输出个人信息。本次基线若无可重复的客户端热点，不触发业务代码或数据库优化。
