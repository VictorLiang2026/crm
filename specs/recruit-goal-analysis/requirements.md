# 招募目标设定和分析

## 目标

在 Console 的招募列表旁建立统一的“目标设定和分析”入口。用户可按起始月和结束月查看八阶段目标、实际达成、月度趋势与当前候选人分布，并为指定月份设置七个可配置阶段的目标与转化参考值。

## 验收

- 点击“招募”时继续显示现有人物式候选人列表，搜索、筛选、排序和打开 Person 均保持可用。
- “目标设定和分析”位于“自然语言删除”左侧，中英文均有明确名称。
- 输入有效的起始月与结束月并查询时，页面显示该区间的阶段目标与实际、逐月趋势；反向区间明确报错，不显示旧查询结果。
- 页面同时显示当前八阶段候选人分布，并明确区分当前存量与按里程碑日期统计的区间达成，不能把两者混为同一个转化率。
- 指定月份的目标和个人转化假设继续使用原 `recruit_goals` 服务保存；草稿须由人点击保存，不因查询或切换月份自动写入。
- 所有新增界面文本由 `i18n.js` 管理；默认简体中文，iPad 宽度与英文均可阅读。
- 不修改任何数据库对象、云函数、旧记录 ID 或删除/恢复行为。
