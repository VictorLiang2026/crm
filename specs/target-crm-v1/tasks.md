把下面这段与所选 WP 一起交给 Codex：

> 只执行本 WP。先读根目录 `AGENTS.md`、环境与安全边界文档，核对本地/GitHub/云端和 `public` 实际结构；列出页面、接口、字段、数据、权限、Legacy 流程影响。若会影响现有功能，先按 `AGENTS.md` 取得针对本 WP 的明确确认再写相关代码。数据库变更同时交 migration/rollback，禁止访问 `pr` / `pr_*`。测试样本只用虚构内容，初始种子总量最多 10 条业务行，先 dry-run，再幂等写入；文本含 `【系统测试·勿联系】`，批次和每条衍生业务/AI 审计记录的 ID 可追踪。样本按普通路径进入 Today、漏斗与 AI，结果明确提示“含测试数据”，不得触发真实外发。执行本 WP 与相邻旧功能回归，记录成功/失败路径；仅部署变更产物，完成 Git 提交、推送、发布标签和三端一致性核对。失败就停止并报告，不顺带修其他功能。报告新增文件、数据变化、测试、未验证项和回滚办法。

## D. AI、命令与学习闭环

- [ ] **WP16｜AI Search 从固定模板走向受控组合查询**　依赖：WP06、WP12、WP14。关联：R07、R14。
  - 交给 Codex：保留模型解析意图与数据库真实筛选分工，扩展可审查的有限查询 DSL/白名单、分页和来源证据，覆盖活动、家庭、关系、保险、招募的组合条件；不让模型生成自由 SQL 或自行编名单。
  - 验收：测试输入命中与不命中结果都由数据库复核；结果含样本时明确标记；无法表达的请求明确拒绝，权限测试通过。
- [ ] **WP17｜Assistant 只读意图执行**　依赖：WP09、WP15、WP16。关联：R07、R08。

  - 验收：自然语言本身、客户端伪造确认、过期/复用令牌均不能写入；测试 Action 经确认只更新一次；手工旧入口回归通过。
- [ ] **WP19｜Opportunity 更新/关闭命令执行器**　依赖：WP10、WP18。关联：R05、R08。

  - 验收：未经确认不改变阶段/截止日期；并发变更触发重新预览；旧机会页及漏斗不回退。
- [ ] **WP20｜Delete 命令的安全边界**　依赖：WP18、WP19。关联：R08、R15。

  - 验收：测试对象的删除/恢复批次准确；旧客户与增员回收站不受影响；其他 delete 请求明确拒绝。
- [ ] **WP21｜Outcome、AI Feedback、Learning 关联**　依赖：WP08、WP10、WP15、WP19。关联：R09。

  - 验收：测试链路能从建议追到决定、行动、结果和学习；拒绝结果不被误算接受；空样本不生成误导性百分比。
