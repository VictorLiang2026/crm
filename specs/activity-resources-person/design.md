# 界面与数据边界

沿用 Console 的品牌红、墨色和翠色状态，使用现有中文/英文字体与卡片、按钮样式。顶部使用明显的“嘉宾资料 / 活动主题”分段按钮；筛选行仅显示当前资源适用的条件。列表卡片将 Person 主资料与活动合作资料分为两个操作入口。

`public.persons` 是身份、姓名、组织与联系方式的主数据。`public.activity_speakers` 保留既有 `name` 历史快照列供兼容，但 Console 读取时优先展示 Person，且不在嘉宾资源编辑器中修改主资料。嘉宾资源维持活动合作阶段、话题、展示头衔、联系安排、次数和备注。`public.activity_topics` 保持独立主题资源。没有数据库或函数修改。

既有 5 位在用嘉宾全部关联有效 Person，快照姓名无差异，主题 1 条。按用户答复关闭 Console 的临时姓名新建入口；旧 admin.html 和云函数保持原状，是否在服务端全面强制关联 Person 需另作兼容评估。
