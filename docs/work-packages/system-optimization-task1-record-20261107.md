# 系统优化任务 1：自动化回归运行器可靠性

完成日期：2026-11-07
工作分支：master
基线提交：5c70140（release-20261106-233800）

## 目标与范围

改善现有离线自动化回归的诊断、分组执行、失败归档和环境故障识别。本任务只修改测试运行器、测试分组、npm 脚本和使用说明；没有修改 CRM 业务页面、云函数、数据库、权限或生产流程。

## 完成内容

- 增加回归运行器核心逻辑及单元测试，覆盖参数校验、测试计数、基础设施故障重试条件和 retry 结果合并。
- 将浏览器基础设施错误标记为独立错误码并记录阶段；失败时记录运行时错误、控制台警告/错误、网络违规、页面路由、视口、浏览器版本和截图路径。
- 只在首次浏览器运行的失败全部属于浏览器启动/CDP 基础设施故障时，用新 profile 隔离重跑一次。恢复的用例标记为 FLAKY 并保留首次失败，不会伪装成首次通过；断言失败不会触发重跑。
- 每次运行按 run-id 保存完整报告、首次浏览器结果及可选重试结果，并继续更新 latest 报告。
- 增加短/长浏览器工作流分组及独立服务层、工具层脚本。测试仍仅使用本地合成夹具，不执行生产业务写入。
