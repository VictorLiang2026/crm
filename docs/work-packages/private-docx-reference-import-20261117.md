# Word 手册导入

发布基线为 efd6f9b（release-20261117-090454）。本工作包只涉及 Console 的话术与异议参考、assistant 和 public 下的私有导入表与 RPC。

在“知识库 → 话术与异议参考 → 导入手册”选择 .docx（单份不超过 2 MiB）。原来的 JSON 导入仍使用原校验流程。可以从“已上传的 Word 手册”重新打开自己最近的 30 份原件。文件按操作人和 SHA-256 去重。

CRM 服务端提取 Word 自然段、编号和标题。配置了 CRM 私有模型时，服务端请求模型给出条目类别及原文段落范围，正文按来源提取。未配置模型时，结构清晰的文档使用本地编号或标题解析，按词项的逆文档频率对已有参考进行相似度匹配。缺少可辨识结构的文档保留原件等待处理。私有模型异常时保留原件并显示待处理。界面注明解析方式及未覆盖段落数。

模型设置属于 assistant 的部署配置：CRM_MANUAL_PRIVATE_MODEL_URL 为 CRM 专用推理服务的完整聊天接口，CRM_MANUAL_PRIVATE_MODEL 为部署配置中的模型名，可选 CRM_MANUAL_PRIVATE_MODEL_TOKEN。仅支持 HTTPS 私网 IPv4 地址或本机回环地址；服务须由 CRM 管理，禁止转发至外部模型。没有公网模型兜底。静态资源、Git 及通用知识 MCP 均不含手册原件。

界面提供来源信息与新旧正文供核对。无明显匹配建议新增，唯一同名匹配建议修订，候选不明确时默认跳过，可显式选择目标或新增。完全相同的条目及同份文件已处理的条目跳过。服务端持有预览与允许的目标 ID；确认仅传预览编号、选中行和目标。数据库按操作人绑定预览，有效期 30 分钟，使用一个事务写入整批。版本冲突或不合法的目标会撤销整批，重放同一确认返回原结果。修订沿用记录编号、既有关键词、启停状态及历史。审核后的新增项会启用。

迁移为 20261117103000_private_docx_import，配对 rollback 仅在私有导入表为空时移除新增对象。存在原件或导入历史时先导出并另行评估。线上仅部署 assistant 和三个 Console 文件（manual-docx-import.js、communication-references.js、i18n.js）。

本地回归包括两份实际 DOCX 的只读条目计数、独立 PostgreSQL 环境下的迁移与空库回滚、租户内按操作人隔离、人工确认、重复上传、重放、并发编辑冲突、保留人工关键词、通用知识库和后台相邻功能。iPad 中英文及生产门禁在主机发布流程中复跑。真实手册须由使用者在 CRM 内预览并确认入库。
