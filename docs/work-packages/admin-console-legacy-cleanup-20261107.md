# Admin Legacy 页面收敛发布记录（2026-11-07）

## 范围

按已确认的五项 Legacy 页面清理范围，将 Console 已具备等价页面的旧入口改为保留书签兼容的跳转，并删除重复页面实现。

- `#/account` → Console `#/settings`
- `#/recruit/goals` → Console 招募目标
- 客户/招募回收站 → Console 回收站
- 客户/招募活动报表 → Console 活动报表
- 独立嘉宾/主题目录 → Console 活动资源目录

保留 admin.html 的客户/人物详情、活动详情及招募工作台行为。招募工作台仍调用的目标渲染逻辑和活动详情使用的嘉宾/主题辅助逻辑继续保留。未改数据库、云函数、权限或业务数据。

## 实现

- 旧 hash 直接打开时跳至对应 Console 页面；保留 URL 查询参数与 hash 内筛选参数。
- 删除 admin.html 中经消费者核对后确认重复的五类旧页面渲染、表单、路由和页面状态。
- 删除已无入口消费者的旧账号设置模块 `crm/js/modules/account-settings.js`。
- 更新路由回归、Console 目录身份确认回归和只读线上巡检用例。
- 删除了综合回归浏览器服务器中该旧模块的静态服务映射。
