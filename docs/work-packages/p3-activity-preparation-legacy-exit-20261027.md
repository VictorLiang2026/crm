# P3e：旧活动筹备入口退出

日期：2026-10-27。基线与回退标签：`45fb94c` / `release-20261026-235410`。

## 范围

- `admin.html` 活动详情撤下旧“AI 筹备助手”和“AI 任务拆解”按钮，以及只供这两个按钮使用的建议渲染和直接创建待办代码。
- 日常使用改走 `console.html` 活动详情中的 Gateway 筹备建议与任务拆解；操作人员核对后使用现有待办编辑器逐项录入。
- 旧活动详情的待办 CRUD、嘉宾推荐、主题维护、人工复盘和其它 AI 功能仍保留。旧 `ai_activity.prepare/decompose` action 本包不删除或改名；数据库、字段、权限、既有记录均不变。

## 影响与回归

- 旧页不再提供一次性“全部采纳”AI 建议任务入口。这与已确认的人工核对新流程一致。
- 检查旧活动详情、待办、嘉宾推荐容器以及 Console 活动筹备入口，并运行跨模块回归。
- 发布仅需部署 `admin.html`。回退时从上述标签恢复该文件、单文件重发并创建恢复提交；不回滚业务数据。

## 后续

- 嘉宾与主题推荐尚未在 Console 有对应 AI 入口，宜放在活动详情“资源”区，与手工选择嘉宾、主题并列；先提供候选与理由，人工选择后走现有写入流程。
- 参与者跟进建议宜放在活动详情“复盘”区；经验总结宜放在活动分析页面。未完成承接前保留旧入口。
