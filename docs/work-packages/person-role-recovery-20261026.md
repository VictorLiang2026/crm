# Person 客户与候选人移出/恢复优化（2026-10-26）

## 范围与影响

- 客户经营视图隐藏“转客户”“转招募”；招募视图隐藏两项转换操作，普通人物列表继续保留。
- 客户经营视图末列改为客户 ID，沿用服务端分页排序并支持升降序。
- 人物详情的客户专属资料增加“移出客户”；候选人资料行末增加“移除候选人”。两项操作复用现有软删除批次，不删除人物，也不改旧入口。
- 再次转入时先查询该人物的已移出记录，展示回收批次预览，由操作者确认后通过 L07 批次接口恢复。恢复后提示已有记录已恢复，并要求继续在原客户/候选人记录上编辑和跟进。关联客户与候选人属于不同批次时分别预览恢复。
- 新增 `person_360` 只读恢复发现 RPC；仅 `service_role` 可调用。扩展客户列表排序字段及允许存在已移出客户时创建 Person-only 候选人的服务端分支。数据库只涉及 `public`。
- 界面文案通过 `i18n.js` 提供简体中文和英文。仅 iPad 布局验收范围。
