# P3f：活动嘉宾 AI 推荐进入 Console

日期：2026-10-27。基线 `245850d7916db535898bf55e262d1f6ae638ad5b`，回退标签 `release-20261027-070437`。

## 范围与影响

- Console 活动详情“嘉宾与主题”增加 Gateway 嘉宾建议。只在筹备期显示，并从至多 20 位在用且关联有效 Person 的资源池嘉宾中推荐；排除本场已确认同一 canonical Person ID 或同一 speaker ID 的嘉宾。姓名暂存的旧参与者仍需人工核对。
- 服务端校验真实登录、活动状态和来源 ID；模型输出里的池外、重复或已参与嘉宾不交给页面。显示的姓名来自 Person 主数据，不采信模型自造姓名。
- 建议只读；点击“核实身份后添加”只预填姓名和嘉宾类型，仍需操作人员搜索并点选 Person 后通过原参与者新增流程确认。AI 不直接建参与者、任务或机会。
- 旧 `admin.html` 嘉宾推荐和 `ai_activity.recommendSpeakers` 暂保留，待 Console 真实账号验证后单独退出。主题推荐、参与者建议与经验总结不在本包。
- 数据库对象、权限和既有业务记录不变；模型由 AI Gateway/CloudBase 配置决定。新增前端文本同时提供简体中文和英文。

## 验证与发布

- 服务端模拟覆盖匿名拒绝、活动状态、参与者上限、无有效 Person、模型伪造/重复 ID、无业务写入；浏览器模拟覆盖双语、人工身份选择窗口以及新增按钮在选人前禁用。
- 活动 PC16、AI Gateway、技能契约、模块化、WP01 全站安全回归和生产匿名拒绝调用按发布输出记录。真实账号下模型输出质量及人工添加真实业务记录未验证。
- 只部署 `ai_activity`、`assistant` 的技能契约副本，以及 `crm/js/modules/console/activity-speaker-recommend.js`、`activity-people.js`、`data.js`、`i18n.js`；不全量上传项目。
- 回退时从上一标签恢复受影响文件并精确重发，创建恢复提交；已产生的 AI 审计历史保留，数据库无需回滚。
