# 知识库 iPad 横屏列表宽度与密度调整

日期：2026-11-20

## 范围

- 仅调整知识库主列表在 iPad Pro 12.9 英寸横屏下的展示，不涉及接口、字段、数据、权限或其他页面。
- 保留完整 8 列、排序、分页、搜索筛选、详情展开和现有操作语义。
- 不改变手机既有布局。

## 调整

- 让 `responsiveTable` 外层网格项横跨搜索/筛选工具区的列，修正原列表被限制在卡片约 60% 宽度的问题。
- 重分配列宽：编号 5%、标题 18%、类别 9%、两列内容各 18%、状态 8%、更新时间 8%、操作 16%。
- iPad 横屏下单元格内边距调整为 8×9px；6 个操作按钮通过单元格内独立 CSS Grid 固定为两列三行。按钮最小高度为 36px，图标收至 12px，并缩小内边距和行间距。
- 操作单元格继续保持原生表格布局，按钮放在独立容器内用两列 CSS Grid 排布，避免直接把表格单元格改成 Grid 后列宽塌缩。
