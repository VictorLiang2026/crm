## 授权与范围

用户明确批准：只开放单个 Person-only 增员候选人的自然语言删除；由人选择确切人物与候选人，服务端产生 15 分钟影响预览，人工确认后执行；恢复仅限同批。开工基线为 PC35 发布提交 `2187b56b0c6d5c06fa84b06c82d2560aff5a736c`、标签 `release-20261018-173836`。隔离工作区 `D:\CRM\crm-pc28-work` 从该提交建立，未修改另一个 master 工作区的未提交文件。该工作区随后将人物目录“最近更新”列独立提交并发布为 `5f8df341f3cbd16c5a19708e466ea749fa80afab`、标签 `release-20261018-1830`；PC28 在此新基线之上无冲突变基，保留其双语字典键。

本包只扩展 Console 招募页、Assistant 的专用命令入口和 `public` 命令台账。Person、客户关联候选人、附件、旧管理页、Legacy Quick Capture 和其他 delete 命令均不在执行白名单内。新界面按 iPad 横竖屏验收，中英双语通过 Console 字典。AI 只提取意图与人物短语，具体模型由 AI Gateway/CloudBase 配置选择，不从模型结果取业务 ID。

## 实施边界

- 服务端依次执行 Command → Plan → Preview → Confirm → Execute；Plan 重新 `resolveName()`，绑定服务端操作者、原请求、人物提及、确切 Person/候选人和幂等键。15 分钟后拒绝未执行命令，同键同内容返回原回执，换人或改内容拒绝。
- 预览锁定人物、候选人及现有跟进，保留完整影响快照；公开视图只显示人物、候选人、活跃跟进 ID/数量、预先已删数量及保留项。确认只接受服务端预览哈希；执行时重读并比较影响集，调用原 `public.crm_person_only_recruit_delete_v1`，核对同批影响后在同事务写入回执。重放只返回原批次。
- 新表启用 FORCE RLS，只有 `service_role` 可读写命令台账、执行 RPC。提供 migration `20261018181500_assistant_recruit_delete.sql` 与保留审计的禁用式 rollback；没有修改既有表或视图。CloudBase code-review 核对了既有登录守卫、服务端身份、RLS、凭据不回显和无客户端数据库直连。SQL 的 `current_user` 只核验数据库服务角色，业务操作者来自已认证云函数身份。
