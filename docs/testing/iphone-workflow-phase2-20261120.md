# iPhone 15 Pro Max 摘要、导航和编辑流程

## 基线与实现

- 发版基线 `c0c6572a00da38832af65189bae2ac5bea135f0d`，恢复标签 `release-20261120-070046`。
- iPhone 人物目录默认展示姓名、身份和最近及下次跟进，活动视图同时提供最近活动入口。原表格可切换，继续支持排序和角色转换。目录选项随页面上下文恢复。
- 人物详情常驻概览和时间线，业务子页在可展开入口下组织，深链接自动打开当前分组。移动端突出记录动作，资料编辑及删除在更多菜单。
- 漏斗阶段和区间活动量增加可选数据条，可查看数值和指标。区间报表支持切换指标，原数据表、统计口径及日期参数沿用现有实现。
- 手机知识编辑依次处理内容、来源与分类、检查确认；必填校验在对应步骤完成，保留同一份表单状态。人物导入依次选文件、映射字段、检查服务端预览及确认。旧平台表单继续走既有提交入口。
- 手机知识编辑、人物导入、快速记录、手工互动及兼容跟进编辑的草稿留在当前页面内存。路由离开、刷新或关闭前尝试提示，弹层取消、关闭、下滑和 Escape 共用同一保护。iOS 强制关闭标签页或回收进程时，浏览器可能不给出提示，草稿会随页面进程结束。
- 静态前端变更。发布检查使用只读 public 权限目录和身份覆盖证据。

## 验证与回退

- 自动化使用隔离合成资料，重点验证 430 × 932 CSS px 的默认摘要、紧凑表格、人物深链接、图表数值、知识步骤、返回取消丢弃、快速记录关闭、导入预览到确认，以及原有 iPad 页面流程。
- WP01 门禁通过。隔离回归 102 项通过、5 项历史预设跳过，匿名权限探测 119 项通过，知识库套件 144 项通过。中英文的 430 × 932 和 932 × 430 视口共 20 个页面样本，未发现整页横向溢出。
- 独立浏览器用例验证知识最后一步才提交、区间活动报表可切换指标后查看指定日期的数值。手机测试还验证了保留与丢弃草稿、导入确认前零写入以及人工互动的取消保护。
- Windows WebKit 27.2 的 iPhone 15 Pro Max 设备配置通过摘要与表格切换、人物导航、草稿取消及图表选择测试。草稿选择测试通过替换确认回调，Safari 原生提示仍需在真机复核。
- 门禁及源码核对结果以本轮发布日志为准。回退时从基线标签恢复本包静态资源，按标准流程发布恢复提交和标签。
- 真机验收包括 Safari 软键盘和地址栏伸缩、手势返回和浏览器关闭提示、VoiceOver 的导航与图表读序、横屏安全区、系统文字放大、中英长标签、iCloud 文件选择、拍照或从照片选取文件，以及真实账号的保存和上传。
