# 2026-10-31 知识库长 PDF 上传自动分卷

## 变更范围

- 知识库上传页在上传前检查 PDF 页数；超过 40 页时，按每卷最多 40 页生成独立 PDF，并逐卷串行上传。
- 文件名和知识标题包含卷号与页码范围。每卷使用现有 `uploadPrepare` → 私有存储上传 → `uploadFinalize` 流程，并分别进入现有待审核流程。
- 新增固定版本 pdf-lib 浏览器资源及其 MIT 许可证；新增 bilingual progress/error text。
- 无数据库、云函数、权限、审核状态或存储桶配置变更。`admin.html` 与其旧实现未修改。

## 安全与兼容边界

- PDF 分卷在本地 Web Worker 中完成，原文只通过现有私有知识库存储上传；worker 一次最多持有一个输出卷并等上传完成再继续。
- 页数无法可靠读取时不创建资料记录、不上传原件；提示检查加密/损坏状态或手动拆分。
- 单卷超过现有 PDF 30 MB 限制时停止并提示压缩/进一步拆分。
- 40 页及以下 PDF 保持单条资料上传；其他格式仍使用原有流程。长 PDF 会形成多条独立资料，各自待审核。
- 如果后续分卷失败，已上传分卷继续处理，页面报告已完成数量；再次上传时由原有内容去重流程处理重复分卷。
