## 原因与改动

- 原版本弹层监听全局捕获 scroll 并直接关闭；隔离环境已复现：打开后滚动 10px 关闭；滚动到第八行后立即展开也关闭。
- 改为通过 animation frame 更新位置，监听可视视口尺寸和位置；原行离开可见区域、点击外部、按 Esc、切换路由或原行移除才关闭。加载中也保持定位；关闭后释放监听器。
- 五列为编号、话术信息、启用与优化、使用版本、操作。类型与关键词合并进话术信息；长标题点击可查看，关键词保留完整 title。三个行操作通过独立 flex 组横排，文字不换行，44px 点击区域，保留原有回调。
- 主操作和搜索筛选分组，搜索按钮使用中英文短文案；标题 16px、版本选择 15px、操作/筛选 14px、辅助信息 13px。
- 沿用既有 CRM 白底 #ffffff、浅灰 #f5f5f7、边框 #e7e9ee、墨色 #2e333b 和强调红 #d31145，以及既有字体栈；这是既有业务表格的可读性修复，不引入新品牌或通用 UI 模板。
- 即时保存、人工版本记忆、历史编辑、待优化队列保持原语义。没有新增模型调用或业务写入入口。
