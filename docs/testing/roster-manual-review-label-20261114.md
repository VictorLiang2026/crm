# 活动名单导入人工复核选项 — 2026-11-14

## 行为说明

`roster_confirmManualReview` 用于确认操作者已人工核对当前导入行的身份、同名候选和重复记录。

该选项不是所有行都必须勾选。以下情况中，当前行不是“跳过”时必须勾选才能进入预览/保存：

- 导入文件中有重复姓名；或
- 系统找到括号外相同/多个候选，但没有唯一精确匹配。

唯一精确匹配使用“确认是同一人并复用”确认；没有相关候选的行可直接导入；跳过行无需人工复核勾选。选择“不是同一人”时，还须完成独立参与者姓名限定词和对应确认。
