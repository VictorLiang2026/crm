# WP2 人物详情七个分区

基线提交为 3153eda，标签为 release-20261111-073920。前端以有效客户档案和有效候选人 ID 分别决定客户经营、团队发展的可见性。保单或招募旧链接在档案已移除时显示原因并回到概览。权限检查由原服务端接口执行。

| 分区 | 入口 |
|---|---|
| 概览 | 人物资料、最近互动、待办，以及机会与行动。机会使用工作区共用的详情和编辑入口 |
| 互动时间线 | 互动记录及原编辑操作 |
| 关系与家庭 | 人际关系、关系网络、家庭 |
| 客户经营 | 客户专属资料、移出客户、保单编辑与检视 |
| 团队发展 | 有效候选人的招募资料和跟进编辑器 |
| 嘉宾与活动 | 嘉宾角色和资料目录、此人物的活动记录及来源链接 |
| AI 与资料 | 摘要、会前准备、话术、跟进建议、历史、事实与洞察、关怀资料和 OCR |

页面顶部“编辑资料”保存同一表单的全部人物、客户和招募修改。原 timeline、insurance、opportunities、relationships、recruit、care、ocr 地址映射至对应内容。

三组专项回归分别为 32、7、5 项通过，覆盖双角色、单角色、无角色、角色失效旧链接、资料保存与冲突、角色移除、行动与承诺、OCR、AI、关系预览确认、中英文、浏览器前进后退，以及五种桌面/iPhone/iPad 模拟视口。两处测试夹具改用独立容器。WP01 全量隔离回归与匿名网关检查通过。生产真人登录、生产业务写入和移动真机未复验。

部署资源为 console.css、i18n.js、pages/opportunities.js、pages/person.js、router.js。恢复时使用基线标签的这五份资源并复核云端哈希，随后以恢复提交发布。
