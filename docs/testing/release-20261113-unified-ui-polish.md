# 发布记录：统一界面细节与主动经营候选

- 日期：2026-11-13
- 基线：`release-20261112-114216`，当前发布前提交 `f7918cb4f7ead056392fe35aae4fd503c761a1f7`
- 目标：生产 CloudBase 静态托管，限本记录列出的页面和模块。

## 变更范围与兼容

- `crm/css/console.css`：统一 iPad 控件高度、间距、边框、聚焦/悬停/按下/禁用状态和等待提示；梳理回收站、搜索筛选与主动经营候选卡片。保留既有手机布局行为。
- `admin.html`：仅增加 iPad 视觉样式覆盖，保留旧单文件实现与业务逻辑。
- `proactive-coach.js`：分层展示身份、来源、原因、证据和提醒；主要操作突出，延后/拒绝收进“更多操作”；执行中明确显示状态。创建仍须服务端预览及人工确认。
- 回收站和批量回收模块：恢复/预览操作期间显示等待状态，原有确认、服务调用、作用范围不变。
- 知识库：失败识别状态展示为失败并保留重试入口，避免失败任务仍显示识别中。
- `i18n.js`：补齐新增中英文提示，通过 `t(key)` 使用。

不改数据库、权限、云函数、API、路由、登录或软删除/恢复语义，不移除旧流程。
