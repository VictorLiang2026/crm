| 旧功能离线 regression | 90 PASS / 0 FAIL / 5 SKIP |

已知现状：19 张旧表仍对 `anon` 授予旧路径所需的表级权限；19 个旧序列对 `authenticated` 仍有 USAGE/SELECT；两个触发器函数的 EXECUTE 对 `anon` 和 `authenticated` 可见。这些被固定为**待审计的现有授权**，不表示建议保留或立即撤销。18 张新服务端表对 `anon` 没有表授权。此工作包不调整任何授权，以免破坏旧云函数路径。

目录授权和匿名网关探针不能证明真实 CRM 登录用户的数据库身份、Cloud Function 内的实际 RDB 凭证，或 RPC 网关对函数 EXECUTE 授权的执行行为。历史隔离账号探针见 `docs/testing/public-permissions-review.md`；本轮未创建隔离记录，也未重跑真实登录用户路径、服务角色密钥或写操作。需要变更权限时，应另开工作包先补这三类运行时验证，再提供 migration/rollback 和完整兼容回归。

本轮仅发布 Git 中的测试/文档产物；云端业务文件无需部署，发布前后使用完整云端源码比对确认未变。
