# 知识库分卷短编号

基线 `54666f9`，正式标签 `release-20261113-110416`。生产短号用于分卷目录、主资料总览的已审核分段、新生成的 AI 引用及总摘要提示中的页段。数据库 ID、主资料号、编辑路由、已有引用、审核范围与资料读取权限均沿用原有机制。搜索支持短卷号、完整卷号、主资料号以及原条目和来源别名。

当前数字系列从 100001 起分配。将 100001 至 109999 的卷号前缀显示为 0001 至 9999；超出这段的未来 ID 保留完整值，避免截断出现重复。测试覆盖两位卷序、前导零、主资料号检索、别名、序列上界、跨系列防碰撞、三种屏宽、双语目录。四份服务端知识投影和总摘要生成提示均通过虚构资料验证，提示测试使用模拟生成器。

专项 3 项、相邻 AI 与知识服务测试 46 项通过。部署范围为 Console 的 knowledge-document.js、knowledge-governance.js，以及 assistant、ai_activity、person_360 的代码。回退短卷号显示可恢复上述五个产物至基线。生产真实设备、真实模型调用不属于本次模拟测试。

私有资料复核稿仅存放在业务草稿与操作人本地文件中。内容审核和整份资料总摘要生成须等待操作人另行确认。
