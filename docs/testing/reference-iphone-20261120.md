## 诊断与视觉设计

- 原手机仍按五列压缩；390px 视口中三个按钮的顶部坐标分别为 534.75、584.75、634.75，形成纵向堆叠。标题、优化选项和版本控件争用窄列，虽然未必产生页面滚动条，阅读宽度仍严重不足。
- 手机改为逐条卡片：编号及标题/类型/关键词 → 启用状态及两个优化勾选 → 使用版本与来源信息 → 三个等宽横向操作按钮。保持同一份 DOM 和处理逻辑，窗口变化不会创建重复控件。
- 工具栏拆为返回、两项主要操作、搜索、双列筛选和分组优化工具；批量选中工具占整行。无新增折叠菜单或额外操作步骤。
- 手机标题 17px、搜索/筛选/版本 16px、行操作 15px、辅助文本 13–14px；保留白底 #ffffff、浅灰 #f5f5f7、边框 #e7e9ee、正文 #2e333b、品牌红 #d31145 和已有字体栈。遵循既有品牌，不另建样式体系。
- 卡片 CSS 作用于宽度 ≤700px 或高度 ≤520px 的粗指针横屏；iPad 768/820/1024 常规视口保留五列表格。已有手机壳层、导航和设备审核不变。
- 使用版本的可见标签复用 t('ro_selector_heading')，不硬编码单语言文字；原表头保留给辅助阅读。
