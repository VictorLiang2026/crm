## 影响与验证

本轮只修改开发配置、文档和工具；admin.html、云函数业务源码、SQL 迁移没有改动。因此无需要覆盖的云端业务产物，发布以 Git 提交、标签及线上一致性复核完成。云端配置只读导出，没有更改线上运行时、权限或环境变量。

- PowerShell 脚本语法检查及无效标签/未提交工作区保护验证。
- `tools/test-release-guards.ps1` 验证 Git 故障时中止，避免网络失败误报一致。
- `codex mcp list` 能识别项目 CloudBase enabled；当前会话新增工具仍需重载，未宣称已完成 MCP 服务端登录验证。
- 发布脚本在提交前和推送后运行完整源码一致性检查；实际运行结果见本次任务输出。
- 本轮没有重新执行登录后的业务操作测试；没有读写业务数据，也未核验数据库迁移状态或依赖包内容。

## 恢复

本轮不改变线上业务行为，无数据库恢复需求。若需撤回工具配置，创建恢复提交还原本轮开发文件；不要恢复/覆盖线上 CRM 业务源码或强推 master。
